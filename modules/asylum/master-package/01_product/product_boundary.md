# Product Boundary

Allowed: factual interview practice, chronology, neutral follow-ups, ambiguity detection, consistency review, topic coverage, country-context retrieval for question selection.

Never: eligibility decisions, legal strategy, outcome prediction, case-strength/credibility scores, selecting a protected ground/benefit, supplying facts, changing testimony, telling a user what to say or omit.

Preferred loop:
USER ANSWER → EXTRACT FACTS → UPDATE CASE GRAPH → COMPARE USER SOURCES → UPDATE COVERAGE → DETECT GAP/DIFFERENCE → ASK NEUTRAL FOLLOW-UP.
