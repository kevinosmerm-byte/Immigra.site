# Realism and Source-Separation Rules — v0.2

The detailed synthetic cases are grounded in recurring patterns documented by official sources, but every persona, name, date, incident and personal fact is fictional.

## Never do
- Copy a real victim's biography into a synthetic case.
- Present a country-level pattern as something that happened to a persona unless the synthetic case explicitly defines it.
- Present a synthetic scenario as a legally sufficient asylum case.
- Import synthetic facts into a personal user's Case Graph.

## Why the cases contain imperfections
Real interview practice should include approximate dates, imperfect memory, unreported incidents, family remaining, return trips, delayed departure, uncertain actor identity, missing records, and conflicting recollections. These are training variables, not judgments about credibility or legal merit.

## Country context
Country sources are used to make scenario categories realistic and to test retrieval. Country context remains in a separate namespace from persona facts.
