# Immigration AI — Bloque 2: Residencia
Motor de contenido y sesiones local para peticiones familiares por matrimonio y relaciones padre/madre-hijo/a.
Instalar Node.js 22+ y ejecutar `npm test`.
No requiere servicios externos. No implementa aún IA de voz, persistencia, autenticación ni backend de producción.
