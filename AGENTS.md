# Identidad y alcance

Este proyecto es IMMIGRA.site. Repositorio canónico: kevinosmerm-byte/Immigra.site; rama objetivo: main.
La migración está integrada en main y Render está conectado a este repositorio. Leer docs/CANONICAL_PROJECT.md para su trazabilidad.
No usar la antigua aplicación de ciudadanía de main previo a la migración como base de la web actual. No confundir nombres internos heredados con repositorios de desarrollo activos.
Preservar las instrucciones adicionales de modules/citizenship/AGENTS.md.
No alterar identificadores nativos, claves de almacenamiento, secretos o datos de usuarios para renombrar el proyecto.
Ejecutar npm run build para cambios de aplicación. Durante la auditoría actual no desplegar automáticamente a producción.
