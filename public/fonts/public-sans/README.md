# Public Sans font assets

Original, unmodified WOFF2 assets from the official U.S. Web Design System Public Sans repository:
https://github.com/uswds/public-sans

Retrieved 2026-10-06 using HTTPS with normal certificate verification. The source branch is `develop`; the SHA-256 hashes below pin the exact downloaded bytes. No external font service is required at runtime.

Public Sans was created for the U.S. Web Design System. This identifies its USWDS provenance; individual government websites use different typefaces. CitizenshipAI remains an independent application.

The original SIL Open Font License 1.1 and project copyright are included in `OFL.txt`. The assets are not transformed or subsetted. These are static faces: declare normal weights 400, 600 and 700 separately in CSS. Intermediate weights select the nearest available face, rather than a variable axis. The upstream README identifies variable builds as experimental; this bundle uses its published webfonts.
