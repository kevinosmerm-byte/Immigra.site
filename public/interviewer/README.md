# Videos de Sahara integrados

Archivos proporcionados por el usuario:
- `Sahara Speaking.mp4` → `speaking.mp4`: se muestra mientras se lee la pregunta.
- `Sahara no speaking (2).mp4` → `listening.mp4`: se muestra en espera y durante dictado.

Los archivos originales se copiaron sin alterarlos. Ambos se reproducen silenciados; el audio de lectura lo produce el sintetizador del navegador. Son videos decorativos, sin sincronización labial con el texto. No se activa cámara alguna.

Se muestra un avatar estático si el video no se puede reproducir o si está activada la preferencia de movimiento reducido. Después de sustituir archivos, ejecuta `npm run build` para actualizar `dist/interviewer`.
